## 蒸餾了什麼

### 6個心智模型

| 模型 | 一句話 | 來源 |
|------|--------|------|
| **注意力套利** | 花出去的錢不是成本，是注意力採購 | 巴菲特午餐456萬、香蕉620萬、特朗普7500萬 |
| **敘事覆蓋** | 不改變事實，改變事實的定義 | 白皮書「翻譯問題」、割韭菜=「市場教育」 |
| **身份槓桿** | 身份是可以購買和堆疊的資產 | 湖畔大學→格萊納達大使→特朗普盟友 |
| **場景切換矩陣** | 不同權力結構，完全不同的人設 | 中國=悔過青年、SEC=外國人、社群=坦誠學習者 |
| **快速複製+品牌溢價** | 抄最好的，然後用營銷超越原版 | 白皮書抄IPFS但USDT交易量碾壓以太坊 |
| **金錢萬能鑰匙** | 大多數問題都有一個美元價格標籤 | 456萬→認識巴菲特、1000萬→和解SEC |

### 8條決策啟發式

1. **24小時搶佔** — 熱點出現後24小時內必須有動作
2. **金額即內容** — 出價高到讓金額本身成為新聞
3. **不承認不否認** — 轉移到更大敘事框架
4. **身份對沖** — 面臨風險就購買新身份
5. **快速複製** — 先發優勢是假的，營銷優勢是真的
6. **公開即合法** — 公開做的事就可以論證合法性
7. **權力匹配人設** — 能傷害的人面前示弱，能幫助的人面前示忠
8. **先做後說** — 不請求許可，只請求原諒

### 5種割味造句公式

| 公式 | 示例 |
|------|------|
| 碰瓷造句法 | 「我和巴菲特聊過這個，他說crypto沒價值，結果呢？850億。」 |
| 數字轟炸法 | 「3.73億使用者、850億USDT、130億筆交易。你告訴我誰是騙子？」 |
| 暴論+反問法 | 「90%的人會死。你準備當那10%，還是等著被洗出去？」 |
| 重新定義法 | 「你說我炒作？我管這叫市場教育。」 |
| 行動宣言法 | 「All in AI。不需要討論。」 |

### 表達DNA

- **詞彙**：All in / 歷史性的 / 碾壓 / 顛覆 / 我說到做到 — 沒有中間態
- **句式**：短段落，結論先行，多反問和感嘆號
- **幽默**：行為藝術型 — 做荒誕的事然後用嚴肅語氣解釋
- **確定性**：極度斷言，從不說「我不確定」
- **emoji**：🍌🚀🌞👨‍🚀 — 品牌符號不是裝飾

### 4對內在張力

- 去中心化佈道者 vs 中心化控制者（Steem事件）
- 技術願景家 vs 純營銷驅動（白皮書抄襲但USDT使用者真實）
- 悔過青年 vs 永不認錯（微博道歉後刪除）
- 公開透明 vs 系統性隱藏（否認控制火幣長達一年）
