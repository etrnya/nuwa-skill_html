# 馬斯克即興思考方式調研

> 聚焦：播客訪談、Twitter Spaces、股東會Q&A、法庭證詞中的即興表現
> 調研時間：2026-04-04
> 來源標註：[他說過的] vs [別人觀察到的]

---

## 一、被追問時的回答方式

### 1. 法庭證詞中的語義反擊

[SolarCity案 法庭證詞] → 律師提問被他認為措辭不當 → 連續五次拒絕回答，說：「We can stare at each other until you rephrase it」→ **思維模式：控制框架權**

他不是迴避問題，而是拒絕在對方設定的語義框架內作答。這揭示了一個關鍵特徵：馬斯克認為**問題的措辭本身就是一種權力結構**，他會先爭奪定義權。

[Tesla案 法庭證詞] → 被問「你理解宣誓說真話的含義嗎？」→ 反問：「This sounds like some sort of legalese, semantic argument. What is the whole truth of something?」→ **思維模式：質疑前提**

即使在法庭這種高壓場景下，他的本能反應不是順從，而是解構問題本身。這跟他的第一性原理思維一脈相承：先問「這個問題成立嗎」。

### 2. CNN採訪中的坦率承認

[CNN採訪 2025] → 被追問X平臺上的不實資訊 → 直接說：「Some of the things that I say will be incorrect and should be corrected」→ **思維模式：機率性自我認知**

注意措辭：不是「我錯了」，而是「我說的一些東西會是不正確的」。這是一種機率化的自我描述，把自己當作一個會出錯的資訊系統來看待，而不是一個需要維護面子的人。

### 3. 法庭中的漫遊式回答

[Tesla案 多次證詞] → 法官不得不多次打斷他的回答讓他回到正題 → 持續給出跑題的、自相矛盾的證詞（與之前的陳述/書面檔案矛盾）→ **思維模式：發散聯想 vs 線性回答的衝突**

[別人觀察到的] Isaacson在傳記中描述：馬斯克不是多工處理者，而是**序列處理者**——他會把全部注意力投入當前單一問題，然後跳到下一個。這可能解釋了他在證詞中的「漫遊」：他的思維在處理一個問題時會自然延伸到關聯領域。

## 二、即興類比和比喻

### 1. 交通問題 = 維度錯配

[Joe Rogan Podcast #1470] → 被問到交通問題 → 即興拆解：「We have a 2D transport system in a 3D living environment. That guarantees traffic. You either go up (flying cars) or go down (tunnels).」→ **思維模式：降維/升維思考**

不是在「如何改善交通」的框架內思考，而是跳出來看問題的幾何本質。

### 2. 火箭成本 = 原材料價格

[TED Talk / Lex Fridman Podcast] → 被問「為什麼火箭這麼貴」→ 當場拆解：火箭由鋁合金、鈦、銅、碳纖維組成，這些原材料在大宗商品市場的成本大約是火箭售價的2%。所以問題不是「火箭為什麼貴」，而是「那98%的溢價到底來自哪裡」→ **思維模式：尋找漸近線（asymptotic limit）**

這是他最經典的即興拆解之一。他不問「如何降低成本」，而是先算出「理論最低成本是多少」，然後反過來問「為什麼現在離理論值這麼遠」。

### 3. 電池成本的同一邏輯

[TED 2017 / 多次播客] → 被告知電池組成本是600美元/kWh → 即興反問：電池的材料成分是什麼？這些材料在倫敦金屬交易所多少錢？算出來只要80美元/kWh → **思維模式：成本的物理極限法**

跟火箭的思路完全一致，說明這不是臨場發揮，而是一套穩定的思維作業系統。

### 4. 硬體 vs 軟體類比

[Nikhil Kamath播客 WTF] → 討論先天vs後天（nature vs nurture）→ 說這是一個「false dichotomy」，用硬體和軟體來類比：基因是硬體，環境是軟體，兩者不是非此即彼 → **思維模式：計算機隱喻重構傳統問題**

### 5. 遊戲作為人生隱喻

[Joe Rogan Podcast] → 談到暗黑破壞神 → 說打敗挑戰「seems like a metaphor for life」→ **思維模式：從日常體驗中提取抽象模式**

## 三、他的問題拆解步驟（五步演算法）

[Tesla/SpaceX生產會議 → Walter Isaacson傳記記錄] → **他說過的，且反覆在內部強調的**

這是馬斯克在工廠會議上即興拆解問題時反覆使用的框架，後來被Isaacson系統記錄：

**Step 1：質疑需求（Question Requirements）**
- 每個需求都要附上一個人名——誰提出的這個需求？
- 不管提出者多聰明，都要質疑
- 「你的最聰明的人給你的需求，才是最危險的，因為你不太會去質疑他們」

**Step 2：刪除零件或流程（Delete Parts/Processes）**
- 刪掉一切可以刪的，甚至比你覺得舒服的多刪一點
- 「如果你最後沒有加回至少10%已刪除的部分，說明你刪得還不夠」
- 這條揭示了一個反直覺的思維：**寧可過度刪減再補回，也不要保守刪減**

**Step 3：簡化和最佳化（Simplify/Optimize）**
- 只有完成了前兩步之後才能做這一步
- 「The most common error of a smart engineer is to optimize a thing that should not exist」

**Step 4：加速（Accelerate）**
- 在簡化之後才考慮提速

**Step 5：自動化（Automate）**
- 最後才考慮自動化
- 「自動化一個不應該存在的流程，是最大的浪費」

**關鍵洞察**：順序不可顛倒。大多數人直覺是先最佳化、再自動化，馬斯克的系統是先質疑存在性、再刪減、最後才最佳化。這個框架的核心哲學是：**先減法，後乘法。**

## 四、改變立場的瞬間

### 1. 對DOGE錯誤的承認

[眾議院共和黨會議 2025.03] → 承認DOGE在審查聯邦預算時犯了錯誤 → 「We will make mistakes, but we'll act quickly to correct any mistakes」→ **思維模式：快速迭代 > 完美計劃**

他把政府工作當軟體開發：快速部署，快速修bug。但這種思維在政治環境中導致了大量爭議。

### 2. 對特朗普政策的轉向

[CBS採訪 2025] → 從支援特朗普轉向公開批評他的「big, beautiful bill」→ 說該法案會增加赤字而非減少 → **思維模式：資料驅動的立場調整**

注意：他不是說「我改變了信仰」，而是說「資料顯示這個方向不對」。立場變化被框架為「資訊更新後的理性調整」，而非情感或政治立場的轉向。

### 3. 承認被自己的平臺極端化

[The Daily Beast報道] → 馬斯克承認自己被Twitter/X上的內容激進化了 → **思維模式：元認知——意識到自己的認知被環境影響**

這是一個罕見的自我觀察時刻：他能夠以第三人稱視角審視自己的認知變化。

## 五、拒絕回答的問題與價值邊界

### 1. 法庭中的選擇性沉默

[Twitter收購案 2025] → 律師飛到華盛頓準備取證 → 馬斯克的律師在預定時間20分鐘後才通知他缺席 → **思維模式：時間作為武器/優先順序的極端排序**

他不是「拒絕回答」，而是直接不出現。這揭示了他的優先順序排序方式：他認為當前正在做的事比法律程式更重要。

### 2. 公開言論 = 私人想法

[Twitter收購案證詞 2026.03] → 被質疑推文是否為操縱股價 → 辯護說：「What I think privately is what I say publicly, there's no difference」→ **思維模式：拒絕區分公私領域**

他聲稱自己不存在策略性溝通：說的就是想的，沒有中間層。這既是一種價值主張（激進透明），也是一種法律策略。

## 六、思維模式總結

從以上即興場景中提取的穩定思維模式：

| 思維模式 | 出現頻率 | 典型場景 |
|---------|---------|---------|
| **第一性原理拆解** | 極高 | 火箭/電池成本、交通問題、所有技術問題 |
| **尋找漸近極限** | 高 | 先算理論最低值，再反推當前溢價來源 |
| **先減後加（刪除優先）** | 高 | 五步演算法、工廠會議、產品設計 |
| **質疑問題本身** | 高 | 法庭證詞、被追問時先解構提問 |
| **機率性自我認知** | 中 | 承認錯誤時不說「我錯了」而說「我的輸出有一定錯誤率」|
| **序列而非並行處理** | 中 | 全身心投入單一問題，然後完全切換 |
| **計算機/物理隱喻** | 中 | 用硬體/軟體類比人的先天/後天 |
| **元認知** | 低但重要 | 承認被平臺極端化 |
| **拒絕框架** | 高 | 不在別人定義的問題框架內回答 |

## 七、矛盾與猶豫之處

1. **類比悖論**：他明確批評「人的思考太受類比束縛」，但他自己大量使用類比（硬體/軟體、遊戲隱喻等）。區別在於：他的類比是從底層概念向上構建的橋樑，而不是從已有方案到新方案的平移。

2. **透明與控制的張力**：他聲稱「公開說的就是私下想的」，但在法庭上又會選擇性迴避、戰略性缺席。他的「透明」是單向的：我選擇什麼時候透明。

3. **快速修正 vs 拒絕修正**：他說「犯了錯會快速改正」，但在很多具體案例中（如對記者的態度、對員工的處理方式），修正來得很慢或者根本不來。

4. **理性框架 vs 情感驅動**：Isaacson觀察到他會在會議上對高管咆哮（demon mode），然後又在絕望中哭泣。五步演算法看起來極其理性，但執行它的人是一個情感波動劇烈的人。
