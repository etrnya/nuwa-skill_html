## 質量檢查清單

審閱已寫的推文/Thread時，逐項檢查：

### 推文檢查
- [ ] Hook是否在2行內抓住注意力？
- [ ] 是否回答了「給誰看/講什麼/為什麼要讀」？
- [ ] 是否有具體性？（數字、時間、人名）
- [ ] 是否能引發回覆？（而非只是點贊）
- [ ] 是否沒有外部連結？（如需要，放第一條回覆）
- [ ] 釋出時間是否在目標受眾的活躍時段？

### Thread檢查
- [ ] 第一條是否獨立成文且引人入勝？
- [ ] 是否遵循1/3/1節奏？
- [ ] 每條tweet是否都推進了內容？（Rate of Revelation）
- [ ] 是否有TL;DR總結？
- [ ] 是否有明確CTA？
- [ ] 長度是否在8-12條？
- [ ] 是否用了bullet points而非大段文字？

### 內容策略檢查
- [ ] 本週是否有至少1條Thread？
- [ ] 是否在大號評論區留了高質量回復？
- [ ] 是否有導流newsletter的CTA？
- [ ] 是否響應了本週的AI熱點？
- [ ] 短推文和Thread的配比是否合理？

## 反模式與避坑

### 增長陷阱（別踩）

1. **買粉/互粉互贊群**：短期資料好看，長期TweepCred暴跌。演算法檢測到不自然的互動模式會降權，得不償失
2. **純工具推薦合集**：AI賽道已是紅海。「10 AI tools you need」這種帖子人人在發，沒有差異化。要發就加你的實測資料和獨特觀點
3. **只翻譯國外AI新聞**：零差異化。要做就加你自己的take——「為什麼這對中國開發者重要」或「我測了，實際效果是...」
4. **過度追熱點丟定位**：每個熱點都蹭，粉絲不知道你到底是誰。熱點要篩選：只蹭跟你定位相關的
5. **只有hook沒有substance**：標題黨短期有效，長期掉粉。Hormozi說「超額交付」，承諾1個給3個
6. **發帖不回覆**：對話權重150x，你不回覆等於放棄最大的演算法槓桿
7. **Thread太長不收**：超過15條tweet開始掉人。Sweet spot是8-12條

### 平臺級風險（需警覺）

- **互動率整體下跌**：2024-2025年X全平臺互動率暴跌48%。不是你的問題，是平臺趨勢
- **Pay-to-play加劇**：非Premium使用者的有機觸達持續萎縮，外鏈帖幾乎為零。Premium不是可選項，是必需品
- **使用者遷移**：部分創作者向Bluesky/Threads分散。但目前X仍是AI/tech內容的主戰場

## 資料覆盤指引

### 關鍵指標（按優先順序）

| 指標 | 看什麼 | 健康值參考 |
|------|--------|-----------|
| Engagement Rate | 互動數/曝光數 | >2%良好, >5%優秀 |
| Reply率 | 回覆數/曝光數 | 越高越好(演算法最重) |
| Profile Visit率 | 主頁訪問/曝光數 | >1%說明人們想了解你 |
| Follower增長 | 周淨增粉絲數 | 冷啟動期日均5-10，增長期日均20-50 |
| 書籤率 | 書籤數/曝光數 | 高書籤=高價值內容 |
| Newsletter導流 | 新增訂閱/周 | 有就是好的，持續追蹤轉化率 |

### 覆盤節奏

- **每天**：掃一眼昨天發的內容資料，標記>500互動的高表現帖
- **每週**：分析本週top 3推文，提取共性→更新模板庫
- **每月**：Review粉絲增長曲線、內容型別分佈、Newsletter增長。調整下月內容策略

### 診斷框架（推文資料差時）

按順序排查：
1. **演算法層**：Premium開了嗎？發帖時間對嗎？有外鏈嗎？
2. **Hook層**：前2行有好奇缺口嗎？有可信度錨點嗎？
3. **內容層**：每條tweet都在推進嗎？有1/3/1節奏嗎？
4. **受眾層**：粉絲量夠觸發Engagement Velocity嗎？先在評論區借流量

## 報告HTML模板要求

診斷報告使用經濟學人/報紙排版風格，必須包含：
- **視覺風格**：襯線字型(Georgia)、暖紙色背景(#f5f0e8)、紅色強調(#C7000A)、Grid佈局
- **資料視覺化**：使用ECharts.js（CDN引入），至少包含話題分佈圖、時間分佈圖、互動漏斗
- **必含板塊**：
  1. Banner + Masthead（一句話核心發現作為標題）
  2. KPI Grid（4個核心指標大數字）
  3. Lead（總結段，斜體，左側紅色border）
  4. 內容ROI分析（按話題分類的互動對比）
  5. 傳播漏斗（點贊率/書籤率/轉推率/回覆率）
  6. 時間分析（最佳釋出時段、釋出節奏演變）
  7. 品牌敘事（敘事角色分佈與互動表現）
  8. Top 5行動建議（編號紅色圓圈 + 標題 + 正文 + 資料證據）
  9. Footer（資料期間、樣本量、分析時間）
