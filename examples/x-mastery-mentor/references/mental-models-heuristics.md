# 核心心智模型（6個）+ 決策啟發式（10條）

> 按需載入：使用者問「為什麼這樣做」「底層邏輯」「思維框架」時，或場景A/B需要深入解釋時讀取。

---

## 核心心智模型（6個）

### 模型1: 精益驗證飛輪

**一句話**：先發最小內容驗證，有效再擴充套件，擴充套件再反哺新內容。

**工作原理**：
```
Tweet（驗證想法）
  ↓ 資料好？
Thread（展開深度）
  ↓ 資料好？
Newsletter/Blog（長文資產）
  ↓ 資料好？
影片/課程/產品（變現）
  ↑ 新想法反哺 ←──────┘
```

**來源**：Cole/Bush(Lean Writing)、Sahil(225+條thread皆先驗證)、Hormozi(tweet→video管線)、Welsh(Content OS)——四個流派獨立收斂於同一模式。

**應用**：想寫長內容前，先問「這個想法用一條tweet驗證過嗎？」

**侷限**：低頻高質路線（如Karpathy）不依賴這個飛輪，靠的是個人權威和內容稀缺性。適合還在建立受眾的階段，不適合已有百萬粉絲的權威人物。

---

### 模型2: 注意力工程

**一句話**：每條內容的前2行決定生死，hook是可以被工程化的。

**核心公式**：

Hook質量 = 好奇缺口 × 可信度 × 具體性

- **好奇缺口**（Cole）：揭示開頭和結局，隱藏中間——迫使讀者點選
- **可信度**：數字、人名、時間錨點（「我研究了1000個賬號...」）
- **具體性**：加限定直到「不舒服地具體」（Cole的Headline Checklist）

**Hormozi的Value Equation應用於Hook**：
```
Hook價值 = (期望結果 × 可信度) / (時間成本 × 努力程度)
```
分子越大分母越小，hook越不可抗拒。

**演算法驗證**：X的Engagement Velocity機制——前15-30分鐘的互動速度決定推文是進入更大流量池還是死亡。Hook決定了這個視窗期的表現。

**操作規則**：
- Hook佔創作時間的50%（寫10-15個版本選最好的——Cole）
- 標題必答三問：給誰看？講什麼？為什麼要讀？
- 參見 `writing-workshop.md > Hook改進示例` 獲取before/after對比

**侷限**：過度最佳化hook會導致標題黨。內容必須兌現hook的承諾，否則長期信任會被消耗。

### 模型3: 品類創造

**一句話**：不是找一個賽道擠進去，而是創造一個只有你的品類。

**三層進化**：

| 層級 | 策略 | 示例 |
|------|------|------|
| 初級 | 找細分賽道(niche down) | 「AI工具評測」 |
| 中級 | Interest Stack組合 | 「AI + 獨立開發 + 產品思維」 |
| 高階 | 品類創造(Category Creation) | 發明新術語，重定義賽道 |

**Cole的Snow Leopard理論**：不做「獅子」（在已有品類裡競爭誰最強），做「雪豹」（在稀有領域佔據獨特位置）。

**Koe的Niche of One**：
- 不找niche，創造niche
- 公式：寬品牌（分享多元興趣）+ 窄產品（針對具體問題）
- Interest Stack：組合多個興趣創造獨特視角（健身+哲學+商業+生活方式）

**Languaging（命名術）**：給你的獨特方法起專屬名字。兩個詞就能改變品類感知（car → electric car）。Ship 30 for 30本身就是languaging的案例。

**Tequila Test（品類檢驗）**：
1. 列出你話題的所有常規建議
2. 全部劃掉
3. 寫剩下的——如果劃掉後什麼都寫不出，說明你還沒有真正的差異化觀點

**應用**：定位不清晰時、感覺跟別人同質化時、覺得賽道太擁擠時。

**侷限**：品類創造需要時間積累和深度專業性，冷啟動階段可能需要先在已有品類裡積累受眾。

### 模型4: 價值前置

**一句話**：把秘密免費給出去，賣執行。每條內容都是一次價值交付。

**Hormozi的核心洞察**：只有1%的人會自己去做，99%的人願意付費讓別人幫他們做。免費給出高價值內容 → 證明你有解決方案 → 建立信任和互惠 → 自然轉化。

**三段式內容結構（Hook-Retain-Reward）**：
1. **Hook**：秒殺注意力（震驚/提問/大膽承諾）
2. **Retain**：持續提供價值（故事+開放迴圈+零廢話）
3. **Reward**：超額交付（可執行的行動建議，比承諾更多）

**Welsh的教育優先**：先用教育內容建立權威，再引導變現。他18周漲44K粉的核心就是「下午發教育性Tips」。

**Sahil的費曼式驗證**：如果你不能用最簡單的話解釋一個複雜概念，說明你還沒理解它。寫作就是費曼技巧的公開實踐。

**應用**：寫每條內容前問「讀者看完能立刻做什麼？」如果答案是「nothing」，重寫。

**侷限**：純價值輸出不建立個人連線。需要穿插個人故事和觀點（Dickie Bush的75/25法則：75%廣度內容拉新，25%深度內容留人）。

### 模型5: 公開建造

**一句話**：把過程變成內容，讓觀眾成為利益相關者。

**兩個變體**：

**Build in Public（levelsio）**：
- 公開收入（MRR截圖）、過程（功能迭代）、失敗（97%專案失敗）
- 核心機制：觀眾看著你從0到$100K MRR，產生「投資人心態」——他們希望你成功，主動傳播
- 分享什麼：MRR里程碑、功能上線、失敗覆盤、技術棧決策、使用者反饋
- 不分享什麼：精確獲客成本、客戶個人資訊、核心實現細節

**Learn in Public（swyx）**：
- 公開學習過程：寫部落格、做教程、在論壇提問和回答——創造「學習廢氣」
- **Pick Up What They Put Down**：大佬釋出新東西時寫評測/解讀/教程並tag他們——他們會轉發，因為「別人誇我的工作，我可以轉發一整天」
- 不需要發明新東西，需要把別人發明的東西解釋清楚

**應用**：AI/科技賽道的核心差異化策略。適合獨立開發者、正在做產品的創作者、技術學習者。

**侷限**：需要你確實在做something。純評論型創作者無法build in public。也需要心理韌性——公開意味著失敗也公開。

### 模型6: 系統化複利

**一句話**：用模板和系統替代靈感，讓內容產出成為可預測的機器。

**Welsh的Content OS**：
1. **策展(Curate)**：收集靈感和表現好的內容
2. **模板化(Templatize)**：把成功內容結構抽象為模板
3. **快速創作(Rapid Create)**：用模板+素材，每小時產出10-20條內容
4. **分發(Distribute)**：跨平臺+自動化工具

**Koe的2 Hour Writer**：
- 1小時散步找靈感 + 1小時寫作編輯
- Idea Museum：有組織的素材庫
- 寫作框架速查：Listicle / 短帖(個人重定義/扎心真相) / PSB故事弧

**內容複用飛輪**：
```
Newsletter（每週1-2篇長文）
  ├── 提取5-7條短帖 → Twitter/X
  ├── Twitter帖子截圖 → Instagram/LinkedIn
  ├── Newsletter朗讀 → YouTube
  └── 高互動推文 → 擴充套件為下期Newsletter選題
```

**Sahil的Notion看板**：原始想法 → 即將寫 → 進行中 → 完成未釋出 → 已釋出。五列管理，永遠不缺內容。

**應用**：感覺寫不動了、靈感枯竭、產出不穩定時。系統讓你在狀態差的日子也能輸出合格內容。

**侷限**：過度系統化會導致內容機械化。需要保留20-30%的「非系統」空間給靈感和即興反應（特別是AI賽道的熱點響應）。

## 決策啟發式（10條）

### 1. 先發推文再寫長文 ← 模型1應用
想寫長內容？先用一條tweet驗證。「Twitter是想法煉油廠，不是廣播渠道。」（Bush）
- **觸發**：任何時候想寫thread/newsletter/影片
- **行動**：發一條tweet測試核心觀點，資料好再擴充套件

### 2. Hook佔50%創作時間 ← 模型2應用
寫10-15個版本選最好的。標題必答：給誰看？講什麼？為什麼要讀？參見「Hook改進示例」。
- **觸發**：開始寫任何內容時

### 3. 對話碾壓一切
演算法權重：對話回覆150x > Reply 27x > 書籤20x > 轉發2x > Like 1x。一條引發作者回復的對話價值超過150個點贊。
- **觸發**：思考engagement策略時
- **行動**：寫能引發回覆的內容（提問、爭議觀點、請求反饋），積極回覆每條評論

### 4. 1/3/1節奏
一句hook + 三句展開 + 一句過渡。讓內容可掃讀。單句行像「檢查點」，給讀者小的多巴胺刺激。
- **觸發**：寫任何超過3句話的內容
- **變體**：1/4/1、1/5/1、1/2/5/2/1

### 5. 超級碗響應（AI賽道）
新模型釋出 = AI賽道的超級碗。響應時間線：0-1h Quick Take → 1-6h Demo → 6-24h 深度Thread → 1-7天完整評測。
- **觸發**：GPT/Claude/Gemini/開源模型重大發布
- **關鍵**：速度 > 完美。第一個有洞察的聲音比第一百個完美分析更有價值

### 6. 擁有你的受眾
演算法會變，email list不會。每條推文的終極目標是導流newsletter。Twitter是發現引擎（top of funnel），newsletter是深度關係（owned audience）。
- **觸發**：內容策略規劃時
- **Sahil資料**：newsletter廣告月收入$70K+，全部再投入增長

### 7. 4A選題矩陣
一個話題 × 4角度 = 無限選題：
- **Actionable**：教讀者怎麼做（Tips/Guides/How-to）
- **Analytical**：用資料支撐（Stats/Trends/Frameworks）
- **Aspirational**：激勵可能性（Lessons/Mistakes/Habits）
- **Anthropological**：觸及人性（Fears/Failures/Lies/Struggles）
- **觸發**：覺得「沒什麼好寫的」時

### 8. 給出秘密賣執行 ← 模型4應用
猶豫「要不要免費分享」時，答案是給。99%的人不會自己做。（Hormozi：零廣告費，6個月100萬粉絲）
- **觸發**：猶豫要不要免費分享某個方法/工具/流程時

### 9. 模板大於靈感
把成功內容抽象為模板，用模板快速生產。Cole只用7種Thread模板寫了200+條thread。Welsh用Content OS每小時產出10-20條內容。
- **觸發**：寫了一條效果好的內容時，立刻提取模板
- **Cole的7種模板**：Framework / Story / Actionable / Curation / Lessons / Mistakes / Contrarian

### 10. 評論區是金礦
大號評論區留高質量回復 = 借流量。Welsh：一條回覆獲得6700次曝光。Sahil冷啟動：把thread發到50個大號評論區，Chamath一次轉推引爆增長。
- **觸發**：粉絲<10K的冷啟動階段
- **規則**：不寫「好帖子」，寫200-400字的「迷你newsletter式回覆」
